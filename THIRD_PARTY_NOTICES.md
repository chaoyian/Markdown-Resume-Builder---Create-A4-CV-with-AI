# Third-party notices

Portable release archives include the following runtime components:

- Node.js, distributed under the MIT license and other compatible licenses. The release archive includes the Node.js `LICENSE` file next to the runtime binary.
- `@marp-team/marp-cli` and its npm dependency tree, installed exactly from `package-lock.json`. Package-specific license files remain inside `node_modules`.

The lightweight release archives do not include a web browser. PDF export uses a compatible browser already installed on the user's system.
