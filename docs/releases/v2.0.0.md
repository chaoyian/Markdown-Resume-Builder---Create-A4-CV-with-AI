# Marp A4 Resume Toolkit v2.0.0

## 中文

v2.0.0 增加跨平台便携发行包、多版本简历选择、首次启动模板引导、衬线主题、环境诊断和完整的跨平台 CI。

下载与你的系统和架构对应的压缩包，解压后运行根目录中的启动器。发行包已经内置 Node.js 和固定版本的 Marp CLI，不需要安装 Node.js 或 npm。PDF 导出仍需要系统中已有 Chrome、Edge、Chromium 或 Firefox；macOS 的 Safari 不受支持。

个人简历保存在解压目录的 `resumes/` 中，PDF 输出到 `output/pdf/`。升级前请备份这两个目录。

## English

v2.0.0 adds portable cross-platform packages, multi-version resume selection, guided first-run template creation, a serif theme, environment diagnostics, and a complete cross-platform CI pipeline.

Download the archive for your operating system and architecture, extract it, and run the launcher at the package root. Node.js and the pinned Marp CLI are included. PDF export still requires an installed Chrome, Edge, Chromium, or Firefox browser; Safari is not supported.

Private resumes stay in `resumes/` and generated PDFs in `output/pdf/`. Back up both directories before replacing a portable installation.
